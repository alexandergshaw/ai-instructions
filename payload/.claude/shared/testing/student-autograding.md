# Student Autograding Rules

- Treat assignment instructions and README files as the source of truth for grading requirements.
- Measure only objectively testable assignment requirements.
- Do not grade unstated requirements.
- Keep test harness files outside student assignment directories.
- Do not modify student-facing assignment requirements merely to simplify testing.
- Remove obsolete harness components only when explicitly replacing them with the standardized harness.
- Provide useful failure information without revealing full assignment solutions.
- Ensure grading behavior is reproducible.
- Distinguish required behavior from optional or bonus behavior.
